# Docket Desktop (macOS)

Docket Desktop is a local, single-user app for invoices and receipts. It opens
PDFs and images in a native window. A person must review and approve each result
before it appears in an export. Contracts and e-invoices remain in the Python
library and CLI; this first desktop workflow handles invoices and receipts.

The desktop app is a separate package in `apps/desktop/` and depends on the
`docket-idp` library. `src/docket/` contains only the library. The `dist/`
folder is generated by the build script; edit `apps/desktop/src/docket_desktop/`
for changes to the native interface or its local document store.

## Run from the source checkout

```bash
cd /Users/artemk/projects/docket
.venv/bin/python -m pip install -e . -e apps/desktop
.venv/bin/docket-desktop
```

Install Tesseract for scanned documents (`brew install tesseract` on macOS).
PDFs with a usable text layer can be read without OCR. The app also needs a
working LLM: set an Ollama host and available model, or choose an
OpenAI-compatible provider and enter its API key in **Settings**. The key goes
to the operating system keychain; it is not written to the document database.
Ollama model names ending in `:cloud` may send document content to a remote
service. Check the model you select before importing confidential documents.

## Use it

1. Use **Add** to choose files or a folder, or drag and drop PDFs and images.
   Identical file contents are detected as duplicates.
2. Open **Settings** and select the provider, model, OCR engine, and document
   languages. Select a document and click **Process** to read it.
   **VLM** beside Process reads the selected document with the configured
   vision model, including PDF pages that have a text layer. It does not change
   the default OCR engine in Settings. This mode can be slower and may send
   page images to a remote service, depending on the selected model. Review
   its extracted values before approval.
3. Review the original beside the extracted fields. Click a field to see its
   source quote and highlighted location when the pipeline supplies one.
4. Correct fields directly. Use **Edit full data / line items…** for nested
   items. Choose **Save edits**, then **Approve**. Invalid totals or schema
   fields prevent approval. Human review is required even if Docket reports
   `succeeded`.
5. **Export** offers Excel, CSV, and JSON for approved documents only. Excel has
   **Documents**, **Line items**, **Fields**, **Processing**, and **History** sheets.
   CSV creates the same five tables as separate files. **Fields** contains every
   corrected value; **Processing** contains the original OCR/LLM result, including
   source citations, validation, and metrics. Long values are split into numbered
   parts so spreadsheets do not truncate them. JSON keeps the complete corrected
   data, original processing result, document metadata, and revision history in
   one file. Source PDF/image files are included in **Settings → Create backup**,
   not in the data exports. Keep backups in a protected location.
   **Restore backup** accepts that ZIP and keeps the previous local data beside
   the app data folder.

The app keeps originals, corrections, approval state, and revision history in
`~/Library/Application Support/Docket Desktop/`. Deleting a document in the app
removes its local original, result, and history. **Restore** checks that the
archive contains a valid database and unchanged source files, then adjusts
stored file paths for the current computer. It replaces the active data set;
the previous one remains in a sibling `Docket Desktop-before-restore-*` folder.

## Build a native `.app`

```bash
cd /Users/artemk/projects/docket
.venv/bin/python -m pip install -e . -e apps/desktop 'pyinstaller>=6,<7'
bash scripts/build_desktop.sh
open 'dist/Docket Desktop.app'
```

The `.app` bundles Python and the Docket runtime. Tesseract and the selected
LLM are external prerequisites. The locally built app is not signed or
notarized, so it is for local testing. Distribution to other macOS users also
requires signing, notarization, a supported OCR installation strategy, and
review of Qt/PySide6 redistribution obligations.
The app icon is `apps/desktop/src/docket_desktop/assets/icon.png`; PyInstaller
converts it to the `.icns` used by Finder and Dock during the build.
